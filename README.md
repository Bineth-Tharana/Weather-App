# **🌤️ Weather App**

A clean, responsive, and interactive weather application built using vanilla web technologies. The app allows users to search for real-time weather information for cities around the globe, displaying current conditions, temperatures, and key meteorological data.

---

## **🚀 Features**

- 🌍 **Real-Time Weather Data:** Fetches up-to-date weather conditions from an external weather API.
- ⚡ **Dynamic UI Updates:** Smooth, real-time UI rendering using JavaScript based on the searched city.
- 📊 **Detailed Metrics:** Displays temperature, humidity, wind speed, and weather descriptions.
- 📱 **Responsive Design:** Optimized for a seamless experience across desktop, tablet, and mobile devices.

---

## **🛠️ Tech Stack**

- 🧱 **HTML5:** Semantic structure for the web page layouts.
- 🎨 **CSS3:** Custom styling and responsive layouts.
- ⚙️ **JavaScript (ES6+):** Asynchronous API fetching, DOM manipulation, and application logic.

---

## **💻 Getting Started**

To get a local copy up and running, follow these simple steps:

### **📋 Prerequisites**

You will need a modern web browser (like Google Chrome, Mozilla Firefox, or Microsoft Edge) and an active internet connection to fetch the live weather data.

### **⚙️ Installation & Setup**

1. **Clone the repository:**
```bash
   git clone [https://github.com/Bineth-Tharana/Weather-App.git](https://github.com/Bineth-Tharana/Weather-App.git)

```

2. **Navigate into the project directory:**

```bash
   cd Weather-App

```

3. **Open the project:**
Simply double-click the `index.html` file to run it locally in your default browser, or use a development server extension like **Live Server** in VS Code.
